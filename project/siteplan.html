Website Planning Document — Week 05

This plan outlines the brand, purpose, target scenarios, color schema, typography, and wireframes for the project's home page.

1. Site Name

ALLAN SMOOKEY'S FASHIONZ — A bold, memorable brand for Gen Z fashion shoppers, focusing on limited drops, sustainable streetwear, and trend curation.

Reason: memorable, brandable, and matches the playful tone the target audience prefers. Optional domain: allansmookeysfashionz.com (example).

2. Site Purpose

  • Showcase latest Gen Z fashion trends with curated product pages.
  • Allow customers to browse, sign up for restock notifications, and purchase limited items (mock checkout in this project).
  • Provide editorial content: trend guides, lookbooks, and styling tips.

3. Scenarios

  1. "I want an affordable, on-trend outfit for a weekend event — what should I buy?"
  2. "Is this item sustainable or ethically sourced, and where can I find similar pieces?"

4. Color Schema (used on this document)

#0F4C5C — Primary: header, CTAs

#2A9D8F — Secondary: accents, highlights

#F4A261 — Accent: buttons, emphasis

#FFFFFF — Background, cards

Accessibility note: high contrast headings on light backgrounds and large font sizes ensure readability for target users. Colors above are used in this document's stylesheet.

5. Typography

  • Playfair Display — Headings, brand wordmark (elegant display for title).
  • Poppins — Body copy, UI text, and small headings (clean geometric for modern look).

Fonts loaded from Google Fonts and used consistently across headings and body text in the project.
